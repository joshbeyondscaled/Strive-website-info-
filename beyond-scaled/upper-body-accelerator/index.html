The method · The PPP Framework

You can't kip what you can't hold.

  1. P1

    Position

    Hollow, arch, active hang, support. The shapes every skill is built on.

  2. P2

    Pattern

    Link those shapes with rhythm and timing, using scales that build the real skill.

  3. P3

    Power

    Turn strength into reps: kipping pull-ups, T2B and wall walks that hold up in a workout.

Position → Pattern → Power. Same as the workshop, now with six weeks of strength behind it.

How the 6 weeks work
